# Research roadmap

This roadmap describes intended work, not completed capabilities.

## Near term

- Freeze a reproducible evaluation protocol, baseline methods, compute budget, and success criteria.
- Improve measurement self-checks and separate instrument error from model inadequacy.
- Strengthen residual-structure detection so the agent can recognize when its current grammar cannot explain observations.
- Track total action cost, including downstream refits and world time.
- Preserve immutable observations, claim lineage, status history, and recovery checkpoints.

## Medium term

- Explore ways for the agent to extend its representational language when current forms are inadequate.
- Evaluate on worlds whose mechanisms are generated independently of development worlds.
- Audit calibration and predictive score across multiple seeds and held-out conditions.
- Test an optional language interface separately from scientific inference.

## Long term research questions

- Can newly formed concepts improve fitting, derivation, experiment design, and research planning rather than remaining descriptive labels?
- Can the agent discover instruments or procedures that make otherwise unmeasurable effects distinguishable?
- How should a research agent balance immediate predictive improvement against expensive experiments whose value arrives later?
- Which kinds of open-ended representation growth can be evaluated without leaking the hidden answer?

Progress will be reported with failures and uncertainty as well as successful results.
