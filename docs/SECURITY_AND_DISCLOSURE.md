# Security and disclosure

This repository is an overview release. The primary engine source, canonical scientific memory, and sealed evaluation assets remain private.

## Do not publish

- API keys, access tokens, passwords, private keys, session cookies, or any credential.
- Personal data, private logs, account identifiers, or private correspondence.
- Canonical memory databases or private backup archives.
- Sealed world specifications, generator seeds, truth tables, or evaluation answers that are still held out.
- Raw run artifacts unless checked for private paths, secrets, and evaluation leakage.

## Before releasing an artifact

1. Identify the source revision and purpose of the artifact.
2. Check it for secrets, private paths, personal data, and sealed truth.
3. Verify that public claims match the artifact and the recorded run.
4. Preserve a private immutable copy where the artifact is part of the scientific record.
5. Do not rewrite an evaluation threshold after seeing its results.

## Reporting concerns

Please contact otherwise532@gmail.com with a description of the concern and enough non-sensitive detail to understand it. Do not include secrets or sealed evaluation truth in a public issue.
